1. ĐỊA CHỈ
--------------------------------------------------------------------------

  API Tải về   : http://192.168.192.32:8800
  Kho nội dung : http://192.168.192.32:9000   (không gọi trực tiếp,
                                              chỉ mở qua link content_ref)

  - Request và response đều là JSON (UTF-8).
  - Chỉ nhận URL thuộc *.hust.edu.vn.
  - IP có thể đổi khi N5 đổi mạng. Nếu không gọi được, liên hệ N5 để lấy IP mới.
  - Kiểm tra kết nối: mở http://192.168.192.32:8800/ping trên trình duyệt.
    Không dùng lệnh ping (Windows chặn ping nhưng API vẫn chạy).


2. TÓM TẮT CÁC API
--------------------------------------------------------------------------

  GET  /ping          Xem dịch vụ đang rảnh hay bận
  POST /load          Gửi 1 URL cần tải -> trả job_id ngay, tải chạy ở nền
  GET  /jobs/{job_id} Xem kết quả: trạng thái, định dạng, link nội dung
  GET  /stats         Thống kê số job, số byte, lỗi

  Luồng dùng:  POST /load  ->  lấy job_id  ->  GET /jobs/{job_id} mỗi 2 giây
               cho tới khi status = "done" hoặc "failed"  ->  dùng content_ref


3. TEST API BẰNG CURL (copy - dán vào terminal)
--------------------------------------------------------------------------

  Các lệnh dưới đây dán được thẳng vào:
    - CMD (Command Prompt) trên Windows 10/11
    - Git Bash, Linux, macOS

  Đang dùng PowerShell: gõ  cmd  rồi Enter để chuyển sang CMD trước khi dán.
  (Trong PowerShell, "curl" là một lệnh khác và dấu nháy bị hiểu khác.)

  Phần  -w " [HTTP %{http_code}]\n"  trong mỗi lệnh chỉ để in thêm mã HTTP
  ở cuối kết quả. Kết quả thật in trên 1 dòng; ở đây ngắt dòng cho dễ đọc.
  Nếu chép lệnh vào file .bat để chạy thì đổi mọi dấu % thành %%.


BƯỚC 1 - Kiểm tra dịch vụ còn sống
-----------------------------------

  curl -s -w " [HTTP %{http_code}]\n" http://192.168.192.32:8800/ping

  Kết quả:
    {"status":"đang chờ"} [HTTP 200]

  status có 3 giá trị:
    "đang chờ"  : không có job nào
    "đang tải"  : đang chạy job, vẫn nhận thêm được
    "đang bận"  : cả 2 luồng đang chạy và có job phải chờ
                  (vẫn nhận thêm được tới khi hàng đợi đầy, xem lỗi 503)

  Không ra kết quả (treo rồi báo lỗi kết nối) = máy bạn không tới được máy N5.
  Báo N5 kèm kết quả lệnh  ipconfig  của máy bạn.


BƯỚC 2 - Gửi URL cần tải  (POST /load)
--------------------------------------

  Trang HTML:
  curl -s -w " [HTTP %{http_code}]\n" -X POST http://192.168.192.32:8800/load -H "Content-Type: application/json" -d "{\"url\":\"https://hust.edu.vn/\"}"

  File PDF:
  curl -s -w " [HTTP %{http_code}]\n" -X POST http://192.168.192.32:8800/load -H "Content-Type: application/json" -d "{\"url\":\"https://bktextile.hust.edu.vn/documents/71926/0/Chuong+trinh+dao+tao+ETM+Da+giay+14.5.19.pdf/fab59942-a4c6-4806-add3-152ad2f6cc24\"}"

  File DOCX:
  curl -s -w " [HTTP %{http_code}]\n" -X POST http://192.168.192.32:8800/load -H "Content-Type: application/json" -d "{\"url\":\"https://clc.hust.edu.vn/xmedia/2025/10/giay-uy-quyen.docx\"}"

  Bắt tải lại kể cả khi nội dung chưa đổi (thêm "force": true):
  curl -s -w " [HTTP %{http_code}]\n" -X POST http://192.168.192.32:8800/load -H "Content-Type: application/json" -d "{\"url\":\"https://hust.edu.vn/\",\"force\":true}"

  Kết quả:
    {
      "job_id": "10431d9b-4b1b-41fc-bd3d-eff1bf115bca",
      "status": "queued",
      "status_url": "/jobs/10431d9b-4b1b-41fc-bd3d-eff1bf115bca",
      "deduplicated": false
    } [HTTP 202]

  -> Copy giá trị job_id để dùng ở bước 3.

  Ghi chú:
    - Body chỉ được có "url", và "force" nếu cần. Thêm trường khác -> lỗi 400.
    - Gửi trùng 1 URL trong lúc nó đang được tải: trả lại đúng job cũ,
      kèm "deduplicated": true.
    - Lỗi 503 queue_full: hàng đợi đầy (22 job), đợi vài giây rồi gửi lại.

BƯỚC 4 - Tải nội dung về máy  (mở link content_ref)
----------------------------------------------------

  Copy NGUYÊN giá trị content_ref ở bước 3 (không sửa), đặt trong dấu nháy kép
  vì link có ký tự &:

  curl -s -w "[HTTP %{http_code}]\n" -o trang.html "<content_ref>"

  Với file PDF thì đổi tên file lưu:
  curl -s -w "[HTTP %{http_code}]\n" -o tailieu.pdf "<content_ref>"

  Kết quả:
    [HTTP 200]   -> file trang.html / tailieu.pdf nằm ở thư mục đang đứng
    [HTTP 403]   -> link hết hạn (quá 15 phút) hoặc bị sửa:
                    chạy lại bước 3 để lấy link mới
    Treo / lỗi kết nối -> máy bạn không tới được cổng 9000 của máy N5

  Nội dung:
    - HTML: mã HTML đã chạy JavaScript (render bằng Chrome headless), UTF-8
    - PDF/DOCX/...: file gốc, mở bằng phần mềm tương ứng

Ý NGHĨA CÁC TRƯỜNG KẾT QUẢ (bước 3)
------------------------------------

    format        "html" hoặc "other"
    extension     định dạng cụ thể: html, pdf, doc, docx, xls, xlsx, ppt, pptx,
                  txt, csv, zip, rar, ...
    content_ref   LINK LẤY NỘI DUNG. GET thẳng, không cần đăng nhập.
                  HẾT HẠN SAU 15 PHÚT -> gọi lại /jobs/{job_id} để lấy link mới.
    final_url     URL sau chuyển hướng (dùng làm gốc để chuyển link tương đối
                  thành tuyệt đối)
    sha256        mã băm nội dung; 2 URL cùng sha256 là trùng nội dung
    size          số byte (file tối đa 20 MB, HTML tối đa 5 MB)
    not_modified / redownloaded / duplicate_content
                  true = nội dung giống lần tải trước
    content_changed
                  true = cùng URL nhưng nội dung đã đổi so với lần trước
    auth_required true = trang cần đăng nhập, không có nội dung

  Các mã lỗi khi status = "failed":
    download_error     nguồn trả lỗi (404, 403, 500...) -> bỏ URL
    auth_required      trang cần đăng nhập              -> bỏ URL
    robots_disallowed  robots.txt cấm                    -> bỏ URL
    timeout            quá thời gian                     -> có thể gửi lại sau
    too_large          file vượt giới hạn                -> bỏ URL
    render_error       Chrome lỗi                        -> có thể gửi lại sau
    storage_error      lỗi ghi kho                       -> báo N5
  (Lỗi tạm thời như 429, 5xx đã được Tải về tự thử lại 3 lần.)

4.1 Nhóm Điều khiển (BAT)
--------------------------

  Việc cần làm:
    1. POST /load {"url": ...}
         202 -> lưu job_id
         503 -> hàng đợi đầy, đợi vài giây rồi gửi lại
         400 -> bỏ URL
         không kết nối được -> dịch vụ đang tắt, thử lại sau
    2. GET /jobs/{job_id} mỗi 2 giây, tới khi done/failed.
    3. done   -> chuyển kết quả cho Đọc nội dung (N1), xem mục 4.2
       failed -> ghi log, bỏ URL (auth_required/download_error không gửi lại)

  Lưu ý:
    - Dịch vụ nhận tối đa 22 job cùng lúc (2 chạy + 20 chờ). Nên gửi cả lô
      rồi mới hỏi kết quả, đừng gửi xong chờ từng URL một.
    - Job được giữ 1 giờ; dịch vụ khởi động lại thì mất các job đang chờ.

  Code mẫu Python (đã chạy thử với dịch vụ thật):

    import time, requests

    DOWNLOADER = "http://192.168.192.32:8800"
    READER_URL = "http://<ip-N1>:6600/parse"

    def submit(url, retries=5):
        """Gửi URL. Trả job_id, hoặc None nếu hàng đợi vẫn đầy sau vài lần thử."""
        for _ in range(retries):
            r = requests.post(f"{DOWNLOADER}/load", json={"url": url}, timeout=10)
            if r.status_code == 202:
                return r.json()["job_id"]
            if r.status_code == 503:              # queue_full -> đợi rồi thử lại
                time.sleep(3)
                continue
            raise ValueError(r.json()["error"])   # 400: URL sai / bị chặn -> bỏ URL
        return None

    def wait_result(job_id, timeout=180, every=2):
        """Hỏi lại cho tới khi job done/failed."""
        deadline = time.time() + timeout
        while time.time() < deadline:
            job = requests.get(f"{DOWNLOADER}/jobs/{job_id}", timeout=5).json()
            if job.get("status") in ("done", "failed"):
                return job
            time.sleep(every)
        return None

    def forward_to_reader(job):
        keys = ("url", "final_url", "format", "extension", "content_type",
                "content_ref", "size", "sha256", "fetched_at")
        requests.post(READER_URL, json={k: job.get(k) for k in keys},
                      timeout=30).raise_for_status()

    job_id = submit("https://hust.edu.vn/")
    if job_id:
        job = wait_result(job_id)
        if job and job["status"] == "done":
            forward_to_reader(job)


4.2 Nhóm Đọc nội dung (N1)
---------------------------

  Gói tin N1 nhận ở POST /parse (đề xuất, cần N1 xác nhận):

    {
      "url": "https://hust.edu.vn/",
      "final_url": "https://hust.edu.vn/",
      "format": "html",
      "extension": "html",
      "content_type": "text/html; charset=utf-8",
      "content_ref": "http://192.168.192.32:9000/hust-raw/raw/...?X-Amz-Signature=...",
      "size": 218210,
      "sha256": "60b5ff8e...",
      "fetched_at": "2026-10-24T11:31:07.462Z"
    }

  Việc cần làm:
    1. GET content_ref để lấy nội dung, TRONG VÒNG 15 PHÚT.
    2. format = "html"  -> giải mã UTF-8, bóc tiêu đề / nội dung / liên kết ra;
                           dùng final_url làm gốc cho link tương đối.
       format = "other" -> đọc theo extension (pdf, docx, xlsx, ...).
    3. Trả 2xx khi đã nhận.
  N1 chỉ nhận job "done", nên không bao giờ nhận trang đăng nhập.

  Code mẫu Python (Flask):

    import requests
    from flask import Flask, request

    app = Flask(__name__)

    @app.post("/parse")
    def parse():
        msg = request.get_json()
        data = requests.get(msg["content_ref"], timeout=60).content   # bytes
        if msg["format"] == "html":
            html = data.decode("utf-8", errors="replace")
            # ... bóc tiêu đề, nội dung, liên kết (base URL = msg["final_url"])
        else:
            ext = msg["extension"]                                     # pdf, docx, ...
            # ... đọc văn bản từ data theo ext
        # ... gửi kết quả sang Tổng hợp (N8)
        return {"ok": True}
