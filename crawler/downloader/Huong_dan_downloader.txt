1. API MẪU VÀ OUTPUT
--------------------------------------------------------------------------

1.1 GET /ping
--------------

  Request:
    GET http://10.177.29.215:8800/ping

  Output (200):
    {"status": "đang chờ"}

  status có 3 giá trị:
    "đang chờ"  : không có job nào
    "đang tải"  : đang chạy job, vẫn nhận thêm được
    "đang bận"  : cả 2 luồng đang chạy và có job phải chờ
                  (vẫn có thể nhận thêm, nhưng nên gửi sang bản khác)


1.2 POST /load
---------------

  Request:
    POST http://10.177.29.215:8800/load
    Content-Type: application/json

    {"url": "https://hust.edu.vn/"}

  Output (202 Accepted):
    {
      "job_id": "e3a596bd-7f3c-4c75-b72f-502c456f0240",
      "status": "queued",
      "status_url": "/jobs/e3a596bd-7f3c-4c75-b72f-502c456f0240",
      "deduplicated": false
    }

  Ghi chú:
    - Body chỉ được có "url", và "force" nếu cần. Gửi thêm trường khác -> lỗi 400.
    - {"url": "...", "force": true} : bắt tải lại kể cả khi nội dung chưa đổi.
    - Gửi trùng 1 URL trong lúc nó đang được tải: trả lại đúng job cũ,
      kèm "deduplicated": true.

  Output khi lỗi:
    400  {"error":{"code":"invalid_request","message":"Body của /load không hợp lệ"}}
    400  {"error":{"code":"bad_json","message":"JSON body không hợp lệ"}}
    400  {"error":{"code":"invalid_url","message":"Chỉ hỗ trợ URL http hoặc https"}}
    400  {"error":{"code":"blocked_host","message":"Host google.com không nằm trong danh sách cho phép"}}
    503  {"error":{"code":"queue_full", ...}}   -> bản này hết chỗ, gửi sang bản kia

  Ý nghĩa các trường chính:
    format        "html" hoặc "other"
    extension     định dạng cụ thể: html, pdf, doc, docx, xls, xlsx, ppt, pptx,
                  txt, csv, zip, rar, ...
    content_ref   LINK LẤY NỘI DUNG. GET thẳng, không cần đăng nhập.
                  HẾT HẠN SAU 15 PHÚT -> gọi lại /jobs/{job_id} để lấy link mới.
    final_url     URL sau chuyển hướng (dùng làm gốc để chuyển link tương đối
                  thành tuyệt đối)
    sha256        mã băm nội dung; 2 URL cùng sha256 là trùng nội dung
    size          số byte (file tối đa 20 MB, HTML tối đa 5 MB)
    not_modified / redownloaded / duplicate_content
                  true = nội dung giống lần tải trước
    content_changed
                  true = cùng URL nhưng nội dung đã đổi so với lần trước
    auth_required true = trang cần đăng nhập, không có nội dung

  Các mã lỗi khi status = "failed":
    download_error     nguồn trả lỗi (404, 403, 500...) -> bỏ URL
    auth_required      trang cần đăng nhập              -> bỏ URL
    robots_disallowed  robots.txt cấm                    -> bỏ URL
    timeout            quá thời gian                     -> có thể gửi lại sau
    too_large          file vượt giới hạn                -> bỏ URL
    render_error       Chrome lỗi                        -> có thể gửi lại sau
    storage_error      lỗi ghi kho                       -> báo N5
  (Lỗi tạm thời như 429, 5xx đã được Tải về tự thử lại 3 lần.)


1.4 Lấy nội dung qua content_ref
---------------------------------

  Request:
    GET <giá trị content_ref, giữ nguyên, không sửa>

  Output:
    200, body là nội dung gốc:
      - HTML: mã HTML đã chạy JavaScript (render bằng Chrome headless), UTF-8
      - PDF/DOCX/...: file nhị phân, đọc theo "extension"

  Lỗi:
    403  link hết hạn (quá 15 phút) hoặc bị sửa -> gọi lại /jobs/{job_id}
