1. ĐỊA CHỈ
--------------------------------------------------------------------------

  API Tải về   : http://10.177.29.215:8800
  Kho nội dung : http://10.177.29.215:9000   (không gọi trực tiếp,
                                              chỉ mở qua link content_ref)

  - Request và response đều là JSON (UTF-8).
  - Chỉ nhận URL thuộc *.hust.edu.vn.
  - IP có thể đổi khi N5 đổi mạng. Nếu không gọi được, liên hệ N5 để lấy IP mới.
  - Kiểm tra kết nối: mở http://10.177.29.215:8800/ping trên trình duyệt.
    Không dùng lệnh ping (Windows chặn ping nhưng API vẫn chạy).


2. TÓM TẮT CÁC API
--------------------------------------------------------------------------

  GET  /ping          Xem dịch vụ đang rảnh hay bận
  POST /load          Gửi 1 URL cần tải -> trả job_id ngay, tải chạy ở nền
  GET  /jobs/{job_id} Xem kết quả: trạng thái, định dạng, link nội dung
  GET  /stats         Thống kê số job, số byte, lỗi

  Luồng:  BAT gửi POST /load  ->  Tải về tải trang/file  ->  Tải về TỰ GỬI nội dung
          sang Đọc nội dung (N1, POST http://10.177.29.30:6600/parse)

  Muốn xem kết quả: GET /jobs/{job_id} tới khi status = "done" hoặc "failed".
  Trường "forwarded": true nghĩa là N1 đã nhận nội dung.

BƯỚC 1 - Kiểm tra dịch vụ còn sống
-----------------------------------

  curl -s -w " [HTTP %{http_code}]\n" http://10.177.29.215:8800/ping

  Kết quả:
    {"status":"đang chờ"} [HTTP 200]

  status có 3 giá trị:
    "đang chờ"  : không có job nào
    "đang tải"  : đang chạy job, vẫn nhận thêm được
    "đang bận"  : cả 2 luồng đang chạy và có job phải chờ
                  (vẫn nhận thêm được tới khi hàng đợi đầy, xem lỗi 503)

  Không ra kết quả (treo rồi báo lỗi kết nối) = máy bạn không tới được máy N5.
  Báo N5 kèm kết quả lệnh  ipconfig  của máy bạn.


BƯỚC 2 - Gửi URL cần tải  (POST /load)
--------------------------------------

  Trang HTML:
  curl -s -w " [HTTP %{http_code}]\n" -X POST http://10.177.29.215:8800/load -H "Content-Type: application/json" -d "{\"url\":\"https://hust.edu.vn/\"}"

  File PDF:
  curl -s -w " [HTTP %{http_code}]\n" -X POST http://10.177.29.215:8800/load -H "Content-Type: application/json" -d "{\"url\":\"https://bktextile.hust.edu.vn/documents/71926/0/Chuong+trinh+dao+tao+ETM+Da+giay+14.5.19.pdf/fab59942-a4c6-4806-add3-152ad2f6cc24\"}"

  File DOCX:
  curl -s -w " [HTTP %{http_code}]\n" -X POST http://10.177.29.215:8800/load -H "Content-Type: application/json" -d "{\"url\":\"https://clc.hust.edu.vn/xmedia/2025/10/giay-uy-quyen.docx\"}"

  Bắt tải lại kể cả khi nội dung chưa đổi (thêm "force": true):
  curl -s -w " [HTTP %{http_code}]\n" -X POST http://10.177.29.215:8800/load -H "Content-Type: application/json" -d "{\"url\":\"https://hust.edu.vn/\",\"force\":true}"

  Kết quả:
    {
      "job_id": "10431d9b-4b1b-41fc-bd3d-eff1bf115bca",
      "status": "queued",
      "status_url": "/jobs/10431d9b-4b1b-41fc-bd3d-eff1bf115bca",
      "deduplicated": false
    } [HTTP 202]

  -> Copy giá trị job_id để dùng ở bước 3.

  Ghi chú:
    - Body chỉ được có "url", và "force" nếu cần. Thêm trường khác -> lỗi 400.
    - Gửi trùng 1 URL trong lúc nó đang được tải: trả lại đúng job cũ,
      kèm "deduplicated": true.
    - Lỗi 503 queue_full: hàng đợi đầy (22 job), đợi vài giây rồi gửi lại.

BƯỚC 4 - Tải nội dung về máy  (mở link content_ref)
----------------------------------------------------

  Copy NGUYÊN giá trị content_ref ở bước 3 (không sửa), đặt trong dấu nháy kép
  vì link có ký tự &:

  curl -s -w "[HTTP %{http_code}]\n" -o trang.html "<content_ref>"

  Với file PDF thì đổi tên file lưu:
  curl -s -w "[HTTP %{http_code}]\n" -o tailieu.pdf "<content_ref>"

  Kết quả:
    [HTTP 200]   -> file trang.html / tailieu.pdf nằm ở thư mục đang đứng
    [HTTP 403]   -> link hết hạn (quá 15 phút) hoặc bị sửa:
                    chạy lại bước 3 để lấy link mới
    Treo / lỗi kết nối -> máy bạn không tới được cổng 9000 của máy N5

  Nội dung:
    - HTML: mã HTML đã chạy JavaScript (render bằng Chrome headless), UTF-8
    - PDF/DOCX/...: file gốc, mở bằng phần mềm tương ứng

Ý NGHĨA CÁC TRƯỜNG KẾT QUẢ (bước 3)
------------------------------------

    format        "html" hoặc "other"
    extension     định dạng cụ thể: html, pdf, doc, docx, xls, xlsx, ppt, pptx,
                  txt, csv, zip, rar, ...
    content_ref   LINK LẤY NỘI DUNG. GET thẳng, không cần đăng nhập.
                  HẾT HẠN SAU 15 PHÚT -> gọi lại /jobs/{job_id} để lấy link mới.
    final_url     URL sau chuyển hướng (dùng làm gốc để chuyển link tương đối
                  thành tuyệt đối)
    sha256        mã băm nội dung; 2 URL cùng sha256 là trùng nội dung
    size          số byte (file tối đa 20 MB, HTML tối đa 5 MB)
    not_modified / redownloaded / duplicate_content
                  true = nội dung giống lần tải trước
    content_changed
                  true = cùng URL nhưng nội dung đã đổi so với lần trước
    auth_required true = trang cần đăng nhập, không có nội dung
    forwarded     true  = đã gửi nội dung sang N1 và N1 nhận (HTTP 2xx)
                  false = gửi sang N1 thất bại (xem forward_error); job vẫn "done",
                          nội dung vẫn lấy được qua content_ref
                  null  = job chưa xong / thất bại, nên không gửi
    forward_error lý do gửi sang N1 thất bại, ví dụ
                  {"code":"forward_error","message":"Module đọc trả HTTP 500"}

  Các mã lỗi khi status = "failed":
    download_error     nguồn trả lỗi (404, 403, 500...) -> bỏ URL
    auth_required      trang cần đăng nhập              -> bỏ URL
    robots_disallowed  robots.txt cấm                    -> bỏ URL
    timeout            quá thời gian                     -> có thể gửi lại sau
    too_large          file vượt giới hạn                -> bỏ URL
    render_error       Chrome lỗi                        -> có thể gửi lại sau
    storage_error      lỗi ghi kho                       -> báo N5
  (Lỗi tạm thời như 429, 5xx đã được Tải về tự thử lại 3 lần.)


4. CÁCH CÁC NHÓM SỬ DỤNG
--------------------------------------------------------------------------

4.1 Nhóm Điều khiển (BAT)
--------------------------

  Việc cần làm: CHỈ CẦN GỬI URL. Tải về tự gửi nội dung sang N1.

    POST /load {"url": ...}
      202 -> đã nhận, xong việc (có thể lưu job_id nếu muốn tra kết quả)
      503 -> hàng đợi đầy, đợi vài giây rồi gửi lại
      400 -> URL sai / bị chặn, bỏ URL
      không kết nối được -> dịch vụ đang tắt, thử lại sau

  Không cần chuyển kết quả sang N1 nữa.

  Muốn kiểm tra (không bắt buộc): GET /jobs/{job_id}
    status "done" + forwarded true  -> N1 đã nhận nội dung
    status "done" + forwarded false -> tải xong nhưng N1 không nhận, xem forward_error
    status "failed"                 -> tải lỗi (404, cần đăng nhập...), bỏ URL

  Lưu ý:
    - Dịch vụ nhận tối đa 22 job cùng lúc (2 chạy + 20 chờ). Gặp 503 thì
      giãn tốc độ gửi.
    - Nên lọc bớt URL ảnh/video (.jpg, .png, .mp4...) trước khi gửi: tải về
      vẫn được nhưng N1 không đọc được nội dung từ ảnh.

  Code mẫu Python:

    import time, requests

    DOWNLOADER = "http://10.177.29.215:8800"

    def submit(url, retries=5):
        """Gửi URL. Trả job_id, hoặc None nếu hàng đợi vẫn đầy sau vài lần thử."""
        for _ in range(retries):
            r = requests.post(f"{DOWNLOADER}/load", json={"url": url}, timeout=10)
            if r.status_code == 202:
                return r.json()["job_id"]
            if r.status_code == 503:              # queue_full -> đợi rồi thử lại
                time.sleep(3)
                continue
            raise ValueError(r.json()["error"])   # 400: URL sai / bị chặn -> bỏ URL
        return None

    job_id = submit("https://hust.edu.vn/")
    # Xong. Tải về sẽ tự gửi nội dung sang N1 khi tải xong.


4.2 Nhóm Đọc nội dung (N1)
---------------------------

  Tải về tự gọi  POST http://10.177.29.30:6600/parse  sau mỗi job tải xong,
  ĐÚNG ĐỊNH DẠNG trong Readme_reader.md của N1:

  Trang HTML:
    {
      "url": "https://hust.edu.vn/vi/news/tin-tuc-su-kien/bai-khac-656090.html",
      "format": "html",
      "encoding": "text",
      "content": "<!DOCTYPE html><html>...</html>"
    }

  File (pdf, docx, xlsx, ...):
    {
      "url": "https://clc.hust.edu.vn/xmedia/2025/10/giay-uy-quyen.docx",
      "format": "other",
      "content_type": "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
      "encoding": "base64",
      "content": "UEsDBBQABgAIAAAAIQ..."
    }

  Ghi chú:
    - "url" là đúng URL mà BAT gửi (chưa qua chuyển hướng).
    - HTML là mã đã chạy JavaScript (render bằng Chrome headless), UTF-8.
    - File tối đa 20 MB (base64 khoảng 27 MB) -> /parse cần nhận được body cỡ này.
    - N1 trả 2xx = đã nhận. Trả 5xx/429 hoặc không kết nối được: Tải về thử lại
      3 lần. Trả 4xx: Tải về không gửi lại.
    - Chỉ gửi job tải thành công; trang 404 hoặc cần đăng nhập không gửi.
    - Cùng 1 URL được BAT gửi lại thì N1 nhận lại nội dung (kể cả khi chưa đổi).
    - Đã chạy thử với N1 thật lúc 20:14 ngày 24/10: 1 trang HTML (128 863 byte)
      và 1 file DOCX (16 828 byte), N1 đều trả HTTP 200.

6. LƯU Ý QUAN TRỌNG
--------------------------------------------------------------------------

  - /load không chờ tải xong; Tải về tải ở nền rồi TỰ GỬI nội dung sang N1.
